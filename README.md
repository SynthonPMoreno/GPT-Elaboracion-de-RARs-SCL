# Synthon · Página de prueba

Página estática en español con diseño adaptable a móvil y escritorio. No requiere instalar dependencias ni compilar.

## Ejecutar

Desde la raíz del repositorio:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

Abre el puerto 3000 desde el visor disponible en tu entorno. Para uso local, visita `http://localhost:3000`.

## Contenido

- `index.html`: presentación, áreas de contribución y enlaces al sitio oficial.
- `styles.css`: estilos, ilustración integrada y adaptación a distintas pantallas.

Es una demostración no oficial. El contenido describe áreas generales, sin atribuir cifras, premios o hitos históricos no verificados. Antes de publicarlo como comunicación corporativa, reemplazar esas áreas por logros documentados y validar textos e identidad visual.
